# RoboGlance Logo

Logo files for RoboGlance

## Files in this repo

- [roboglance.svg](./roboglance.svg): main logo (used to generate other logo file types)
- [RoboGlance.icon](./RoboGlance.icon): Icon Composer icon automatically copied into [roboglance-apple](https://github.com/roboglance/roboglance-apple)
- [scripts/extract_layers.py](./scripts/extract_layers.py): pulls out svg layers into separate files for Apple icon
